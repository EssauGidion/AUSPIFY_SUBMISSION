 Netflix Machine Learning Internship Projects

Overview
This repository contains practical Machine Learning projects completed during the "Auspify Technologies Machine Learning Internship Program".
The projects use the Netflix dataset to explore recommendation systems, predictive modeling, classification, and unsupervised learning using Python.

Completed Tasks

Task 1: Netflix Content Recommendation System
- Developed a content-based recommendation system.
- Used TF-IDF for text feature extraction.
- Applied Cosine Similarity to identify similar Netflix titles.
- Generated recommendations based on content attributes.

Task 2: Content Type Prediction Model
- Developed a model to classify Netflix titles as Movies or TV Shows.
- Applied categorical encoding and feature preprocessing.
- Trained and compared multiple classification algorithms.
- Evaluated model performance using accuracy.

Task 3: Netflix Audience Rating Classification
- Developed a multi-class classification model to predict audience ratings.
- Applied Decision Tree and Random Forest algorithms.
- Used hyperparameter tuning to improve model performance.
- Evaluated models using classification metrics.

Task 4: Netflix Content Segmentation
- Applied K-Means clustering to group Netflix titles.
- Used One-Hot Encoding and Standard Scaling.
- Identified five content clusters.
- Visualized clusters using TruncatedSVD.
- Analyzed cluster characteristics and content patterns.
